# 免费X账号接入

2026-10-14核对，当前版本与运行见项目状态。当前电脑已有登录配置，真实实采和推荐证据见v0.11.0/v0.12.0报告；自然过期后的恢复仍需观察。采用开源[twscrape](https://github.com/vladkens/twscrape)和自己的X账号，无需SocialData充值或开发API，AI筛选另计模型用量。

## 日常使用

工作台「连接与设置 → X接入方式」默认「免费 · 自己的X账号」。开启「加入X热门搜索」后，X与网页一起进入每日筛选，共用默认最多3条的推荐总上限，质量不足少推。正式库按2026-10-19反馈开启自动探索，隔离主目录保持关闭；点击「发现新内容」可手动开始当天批次。连接同一后台的两库共享X日缓存及请求次数。

八板块轮流组成最多三组近七天Top搜索，各取首页最多20条、不翻页。三次是应用层首页检查数量；采集库可在一个检查内做协议初始化或有限重试，每次有55秒/65秒超时上界。最多9条X候选与网页合并至最多24条，最终由已有AI流程筛选。X搜索不是全站官方热榜，返回量与内容质量随实际结果变化。

v0.17.0对每批最多三条实际文章/项目外链补读摘选，每帖一条，保留对应网页原件，不扩展回复或整个线程。推荐价值与原作者陈述/转述、未读/未看等覆盖说明分开；未知作品份量不按低分处理。原帖和外链摘选分别保留，外链日期不覆盖原帖日期；不会把视频时长当作视频内容，收录帖文也不等于收录外链全文。

服务按北京时间保存每日批次，各阅读目录共享首次结果与查询。重复打开或同日检查不重搜。原响应单独保存并校验；缺日期、过期或未来帖子不进入近七天候选，缺互动数据不编造零。

## 观看与收录

X视频卡片显示实际附件时长并提供“打开X视频”；仅由原始接口证实有视频，尚未取得文字稿。帖子实际包含的安全外链也可直接打开。

“收录正文”保存本条完整公开帖文和接口原件，不抓登录页、不把视频介绍当文字稿，不获取外链文章、回复或整个讨论串。按推荐归属存入当前阅读目录；重复收录去重，已有批注保留并报告冲突。X原件取自已校验缓存，不新增搜索或模型调用。

## 登录失效

无需按天重复登录。失效时点击「连接X账号」，在专用窗口登录，再点「检查X连接」。系统只保存专用窗口的X登录状态，不读取你平时浏览器的其他账号；不用在聊天里发送密码或Cookie。

网络故障、限流及接口变化也可能导致失败，不能仅凭一次失败判断必须重登。失败停止当天后续搜索，保留已有内容，其他渠道继续运行；次日可重新检查。重登不会清空当天批次，也不会自动重复当日未知请求。X账号验证只能由用户在专用窗口完成。

已验证正常登录、真实搜索、服务进程重启缓存、真实AI筛选和正文收录；缺配置/失效式失败/跨天恢复另经受控时钟及依赖测试。实际会话自然过期后的重登、物理重启/休眠和跨实际日期自动采集尚未实机验收。非官方网页接口可能变化，需要维护，本次成功不代表长期稳定保证。

## 新电脑安装

先准备项目Node依赖、本机后台和Python 3。在项目目录执行：

```powershell
npm run x:setup
npm run x:login
```

第二条打开专用窗口，由用户登录。Python安装在项目`.local/x-free/venv`，twscrape固定已核验提交`568844df82af956df5970bcf7ff84dd5ba729eb0`，不静默追踪主分支。原订阅和模型配置保留。

## 本机配置与恢复

- `.local/x-free/browser-profile`：专用浏览器状态。
- `.local/x-free/auth.json`及`accounts.db`：X凭据，仅本机保存，不分享或写入Vault。
- `.local/x-free/login-status.json`：无凭据的窗口状态。
- 材料服务数据目录`free-x/state.json`及`free-x/receipts/`：日批次与公开帖子响应，含校验摘要。

Windows中文路径导致libcurl证书错误77时，程序复制公共CA证书到ASCII临时路径，保持TLS验证开启。复用本机后台已有系统代理，不购买代理或额外账号。

未安装依赖时运行`npm run x:setup`；专用窗口正在打开时不要重复启动。原件缺失或摘要异常时保留记录检查，不通过删除日记录冒充成功。SocialData为明确选择后的可选付费渠道，不自动切换。
