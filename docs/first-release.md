# v0.22.5 能做什么

| 能力 | 使用范围 |
| --- | --- |
| 固定订阅 | 单公众号 RSS、YouTube、B 站、通用 RSS/Atom，按来源和作者发布日期浏览。可选择 1～7 天补收，受上游窗口和日期校验限制。 |
| 探索与选读 | 按兴趣和阅读预算挑少量内容。推荐价值和证据覆盖分别记录。X、搜索和模型均按各自设置启用。 |
| 阅读库 | 链接、HTML、Markdown、PDF、视频条目和文字稿。正文、原件、AI 短导读分开保存。回收站可恢复，保留笔记与历史版本。 |
| 知识接续 | 明确选择一份材料，通过已验证兼容的 Claudian 接口讨论或交接 Wiki。正式 RAW/Wiki 核验需要实现对应的 Vault 工作流。 |
| 本机后台 | 网络故障可退避及恢复补检查，保留每轮回执，账本分页同步。持续采集依赖本机运行和来源可达。 |

未提供平台级全量历史、付费正文绕过、通用 ASR、自动写 Wiki 或官方 Obsidian 社区列表发布。详见[完整工作流](workflow/public/zh-CN/README.md)与[安装指南](../README.zh-CN.md)。
